# NLP_Trigram_next_word_predictor

This project is a basic trigram next‑word prediction system. A trigram uses two previous words to predict the next word. The Python file in this repo (next_word_predictor.py) handles preprocessing, trigram counts, probability calculation, next‑word prediction, and text generation.

How It Works
The text is lowercased, punctuation removed, and split into tokens.

The script loops through every group of three words to build trigram counts.

Counts are converted into probabilities for each possible next word.

Given two words, the model returns the top predicted next words.

Text can be generated by repeatedly predicting the next word until no more trigrams exist.


How the trigram model predicts the next word
The model looks at the previous two words and checks if that pair exists in the trigram dictionary. If it does, it retrieves all possible next words and their probabilities. The next word is chosen based on the highest probability. It’s a simple count‑based statistical model that only uses patterns found in the training text.

Limitations of using only two previous words
Using only two words of context is very limited. It cannot understand long‑range meaning, grammar, or sentence structure. It only works if the exact word pair exists in the training data. It cannot generalize or reason. Modern language models use deep neural networks and large amounts of data, allowing them to understand context across entire sentences or paragraphs. A trigram model is simple and predictable but far weaker than modern AI systems.
